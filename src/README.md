# src/

処理スクリプトを置く。**タスクごとにサブフォルダを切り**、コードを書き始める前に
そのフォルダに`instruction.md`(指示書)を作る。

```
src/
└── <タスク名>/
    ├── instruction.md   # 今回の作業指示書(下記の雛形)
    └── (コード本体)
```

## instruction.mdの雛形

```markdown
# <タスク名>

## 目的
(何のための処理か。CLAUDE.mdのどの方針・未決事項に対応するか)

## 計算・処理してほしいこと
(具体的に。「専用道路の定義」のどの条件を使うか、パラメータは何か)

## 入力
(`data/`配下のどのファイルか。出典は`data/datasets.txt`に記載済みか)

## 出力
(`data/processed/`や`results/`のどこに、どんなファイル名で出すか。
 条件が分かるファイル名にする)

## 確認してほしいこと
(結果の見方。連結成分の数、延長、目視確認用の地図など)
```

## 方針(CLAUDE.mdの要約)

- 対象地域・「専用」の定義・許容する横断の条件などは、設定ファイルに出し、
  コードの奥に埋め込まない(条件を変えて比較できるようにする)
- 出力先はすべて`results/`または`data/processed/`。リポジトリ直下に新しい
  トップレベルフォルダを作らない
- 最初のタスク候補: 対象地域でのOSM `highway=cycleway` 等の延長・連結性の集計
