近距離検索(専用道路ネットワークのみ)

地図をクリックして出発地・目的地を指定してください。自転車専用道路 (highway=cycleway)だけをブラウザ内でつないだ経路を探します。 専用道路網は地域ごとに分断されているため、離れた地点間では「経路が 見つかりません」と表示されることがあります(その場合は下の事前計算ルートを 確認してください)。
