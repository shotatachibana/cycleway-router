近距離検索

地図をクリックして出発地・目的地を指定してください。専用道路を最優先に、 繋がらない場合は自転車レーン・車道混在(矢羽根等)、それでも繋がらない 場合は出発地・目的地周辺の一般道路網(その都度読み込みます)も使って ブラウザ内で経路を探します(専用道路ほど優先度は高くありません)。 それでも繋がらない場合は「経路が見つかりません」と表示されるので、 その場合は下の事前計算ルートを確認してください。

長距離ルート(事前計算済み)
