# data/

## フォルダの役割

| フォルダ | 内容 | Git管理 |
|---|---|---|
| `raw/` | 生データ(OSM PBF、自治体オープンデータなど)。取得スクリプトで再現する | 対象外(`.gitignore`) |
| `interim/` | 前処理の途中データ(絞り込んだPBF、R5のネットワークキャッシュなど) | 対象外(`.gitignore`) |
| `processed/` | 自転車専用道路ネットワーク等の成果データ。`raw/`から再計算できるもの | 対象 |
| `datasets.txt` | 使用データの一覧(出典URL・取得日・ライセンス・出典表記) | 対象 |

## 注意

- **100MB超のファイルはGitHubにpushできない**。OSMのPBFや中間ネットワークは容易に
  超えるので、`raw/`・`interim/`はコミットしない。`processed/`に大きな成果物を置く
  場合も、コミット前にサイズを確認し、必要ならParquet等の軽い形式を検討する
- **新しくデータを使うときは、必ず`datasets.txt`に追記**する(出典URL・取得日・
  ライセンス・必要な出典表記)。Webの画面上にも、必要な出典表記
  (例: © OpenStreetMap contributors)を表示する
- `raw/`が空のときは、生成AIが勝手に大量のデータをダウンロードせず、まず取得対象・
  容量・ライセンスをユーザーに報告して確認する
- OSMのデータはODbLライセンス。加工したデータを`docs/data/`で公開する場合の
  出典表記・ライセンス上の扱いは、公開前に確認する
- OSMの地域別PBFは、Geofabrik(https://download.geofabrik.de/)から取得できる。
  日本全体は大きいので、地方単位のファイルを取得するか、`osmium extract`で
  対象地域だけに切り出してから使う
